# 操作
```
docker build -t yuchuli-sqli .
docker run -d -p 7777:80 --name yuchuli-sqli yuchuli-sqli
docker build -t yuchuli-sqli . 2>&1 | tee build.log
```
> 可以保存下来发给别人使用
```
docker save -o yuchuli-sqli.tar yuchuli-sqli
docker load -i yuchuli-sqli.tar
docker run -d -p 8080:80 yuchuli-sqli
```
