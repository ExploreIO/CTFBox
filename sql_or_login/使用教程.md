# 使用

一般使用

```bash
docker build -t sql_or_login .
```

使用代理

```bash
docker build --build-arg HTTP_PROXY=http://10.10.109.40:7897 --build-arg HTTPS_PROXY=http://10.10.109.40:7897 -t sql_or_login .
```

运行

```bash
docker run -d -p 80:80 sql_or_login
```

保存

```
docker save -o sql_or_login.tar sql_or_login
```
