# CVE-2026-31431 漏洞靶场使用教程

## ⚠️ 安全警示
本靶场仅限在**断网的本地虚拟机**中使用。严禁在任何生产环境、云服务器或存有敏感数据的设备上运行。

## 环境要求
- 已安装 Docker 的 Linux 系统
- 内核版本在 CVE-2026-31431 影响范围内（如 6.12.x）

## 文件结构
```
your-lab-dir/
├── Dockerfile
└── cve2026-31431.py
```

## 使用步骤

### 1. 构建镜像
```bash
docker build -t cve-31431-deb13-lab .
```

### 2. 运行容器
```bash
docker run -it --name deb13-cve-lab cve-31431-deb13-lab
```

### 3. 进入容器后，查看脚本
```bash
ls -la /lab/
```

### 4. 确认当前是低权限用户
```bash
whoami   # 输出: victim
id       # 输出: uid=1000(victim) gid=1000(victim)
```

### 5. 执行漏洞利用脚本
```bash
python3 /lab/cve2026-31431.py
```

### 6. 验证提权成功
```bash
whoami   # 输出: root
id       # 输出: uid=0(root) gid=1000(victim)
```

## 效果展示
```
victim@容器:/lab$ whoami
victim
victim@容器:/lab$ python3 /lab/cve2026-31431.py
# whoami
root
#
```
从普通用户 `victim` 到 `root`，提权成功。

## 清理
```bash
docker rm -f deb13-cve-lab
docker rmi cve-31431-deb13-lab
```
